🚀 QUICK START:
═══════════════

1. FIRST TIME? Install Rust:
   
   Visit: https://rustup.rs/
   
   Then run:
   rustup target add wasm32-unknown-unknown

2. TO RUN BOTH INSTANCES:
   
   Double-click: START_INSTANCES.bat
   
   OR in PowerShell:
   .\start-both-instances.ps1

3. TO BUILD BOTH INSTANCES:
   
   Double-click: BUILD_BOTH.bat
   
   OR in PowerShell:
   .\start-both-build.ps1


📖 WHAT HAPPENS:
═════════════════

→ Two terminal windows will open
→ Instance 1 runs in one window
→ Instance 2 runs in another window
→ Both run completely independently
